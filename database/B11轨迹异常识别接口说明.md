# B-11 轨迹异常识别

按作业单分析 B-08 的原始或归档轨迹，向 C-05 返回带时间和坐标的异常标记。查询即时计算，结果供人工复核。轨迹、面积和结算数据保持原有口径。

## 调用

```text
GET /trajectory/playback/anomalies?trajectoryId=<作业单号>&type=ORIGINAL
```

`trajectoryId` 必填，原样传入字符串。 `type` 为 `ORIGINAL` 或 `EFFECTIVE`，两类数据分别分析。可指定 `startTime` 和 `endTime`，按北京时间填写，例如 `2026-11-27T08:00:00`。权限、24 小时范围和 50000 点上限沿用 B-08。需要登录并有权查看该作业单。

## 默认规则

| 标记 | 判定 |
| --- | --- |
| `GAP` 疑似漏采 | 仅原始轨迹。两个相邻采样时间相隔超过 60 秒，记录缺口的两端 |
| `ARCHIVE_GAP` 归档断点 | 仅有效轨迹。相邻归档点相隔超过 60 秒。地块筛选或历史归档都可能造成这种断点 |
| `STOP` 停留 | 连续采样点都在该段首点的 5 米范围内，且持续至少 60 秒。出现缺口或回放断段时结束该段 |
| `GPS_SPIKE` 疑似定位跳点 | 同一片段内，连续三点的前后两跳各至少 30 米、各不超过 3 秒，且第三点回到首点 5 米范围内。标出中间点，并从速度、停留和转场判断中隔开涉及跳点的两条边 |
| `OVERSPEED` 推断超速 | 连续相邻点的直线距离除以时间，换算速度大于 20 km/h。先应用孤立跳点规则，再检查剩余连续边 |
| `TRANSFER_CANDIDATE` 疑似转场 | 连续采样线段均位于当前地块外环之外，至少有一个点距该段起点 30 米或更远。原路折返仍保留这段记录。跨过地块、接触边界、断点或跳点都会结束该段 |

这些是本版默认值，响应 `rules` 会返回数值和单位。缺口检测只比较已有点的采样时间，任务开头、结尾以及空轨迹还需要结合设备上报记录复核。有效轨迹分析只读取归档，排查设备漏采时另查 `ORIGINAL`。跳点规则只能识别符合上述模式的孤立偏移，遇到连续漂移或真实急转仍需查看原始点。转场依赖当前地块外环，内部空洞和排除区仍属于外环内部。

## 展示数据

- `events` 按起点顺序返回，`kind` 对应上表。
- `start`、`end` 含回放的从零开始的 `segmentIndex` 和 `pointIndex`，以及各自的 `point`（WGS84 经纬度和带时区时间）。前端可用这些点显示标记或定位回放。
- `durationSeconds` 为起止时长，`displacementMetres` 为起止直线距离，`inferredSpeedKmh` 仅在超速标记中提供。
- 转场标记的 `maxDisplacementMetres` 为这段内距起点最远的距离。往返轨迹的起止位移可能为 0，最远距离仍会保留。
- 跳点标记的 `spikePoint` 指向中间可疑点，`start`、`end` 为相邻证据点。渲染异常时，将 `GAP` 和 `ARCHIVE_GAP` 的两端作为断点，并将 `GPS_SPIKE` 画在 `spikePoint` 位置。
- `transferChecked` 表示本次有可用于判断转场的地块外环。`warnings` 包含无轨迹、无边界或回放数据质量提示。出现此类提示时，空事件列表只代表按现有数据未检出。

重新构建并启动 CMS 后，在 Swagger 的「06-轨迹管理」登录授权，选择一个已有原始或归档轨迹的作业单，分别执行两种 `type`，对照 B-08 回放核查标记两端。C-05 可接入此接口展示标记，B-12 另行处理人工修正与日志。

回归场景覆盖同一批轨迹筛点后只出现归档断点、场外折返保留最大位移、单次跳点独立标记，以及持续高速、回放断段仍按原规则处理。

## 原始数据源不可用时演示

正式查询报「原始轨迹数据源暂不可用」时，可用合成轨迹演示检测规则。样例单号为 `DEMO-B11`，响应中的 `source` 为 `DEMO_FIXTURE`。算法与正式查询共用，样例本身在内存中，正式查询继续使用真实数据源。

```text
GET /trajectory/playback/anomalies/demo?type=ORIGINAL
GET /trajectory/playback/anomalies/demo?type=EFFECTIVE
```

| 参数 | 预期标记 |
| --- | --- |
| `ORIGINAL` | 停留、推断超速、定位跳点、80 秒疑似漏采、场外折返疑似转场 |
| `EFFECTIVE` | 停留、推断超速、定位跳点、80 秒归档断点 |

在本地 CMS 的 `deploy/dev-tunnel/dev-local.env` 添加 `AGRI_DEMO_TRAJECTORY_ENABLED=true`，重新构建并启动后，登录 Swagger 的「06-轨迹管理」，展开「B-11 轨迹异常识别演示」。点 Try it out，选择 `type` 后执行，演示接口无需填写真实作业单。该接口默认关闭。

本机开发模式还可在「业务管理 → 轨迹与面积核算 → 查看演示轨迹」打开样例详情。前端开发服务器从本机 8091 读取 `/trajectory/playback/anomalies/demo/workorder`，展示 12 个轨迹点、5 种异常标记和 B-10 算出的面积。播放保留采样缺口和跳点两侧的断线，可在异常列表定位。样例详情独立于真实列表，无法提交复核。
