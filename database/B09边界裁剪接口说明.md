# B-09 边界判断与轨迹裁剪

对接 A-12 作业助手与 C-05 轨迹核算。复用原有面积计算的 WGS84 输入校验和局部米制投影，新增中心线裁剪与只读检查接口；不重写作业助手，不生成作业单，不回填面积，不删除 GPS 点，无新增表结构。

## 业务规则

| 定位状态 | 含义 | inBounds |
| --- | --- | --- |
| `INSIDE` | 地块内部，且不在启用的额外排除区 | true |
| `BOUNDARY` | 恰好在地块多边形边缘或顶点 | true |
| `OUTSIDE` | 地块之外或原生多边形空洞内部 | false |
| `EXCLUDED` | 插花地启用的排除区域内部或边缘 | false |
| `UNAVAILABLE` | 边界缺失、为空、无效或坐标系错误 | null |

边界状态包含外环和原生空洞环的边缘；插花地额外排除区连同其边缘都排除。不存在或无权查询的地块由新接口返回权限错误，不泄露其存在性。

A-12 旧判断使用 `ST_Contains`，现在改用含边缘的 `ST_Covers`，并检查几何有效性、SRID和插花地排除区。保留 `WorkOrderGeoMapper.countPointInside` 调用签名：界内或边界返回1，界外或排除区返回0，边界不可用时抛出明确异常。

作业助手处理方式：独立超界工具在边界不可用时返回“暂时无法核对”；开始／结束作业仍沿用“超界只提醒”的业务策略，无法核对时给出未确认提示，不伪称已在界内。定位仍可全部省略；只给经度或纬度、NaN、无限值和越界值会被拒绝，不创建或结束作业单。

## 1. 定位点检查

```text
GET /landPlot/boundary/check?plotId=<实际地块ID>&longitude=114&latitude=38
```

示意返回：

```json
{"code":200,"msg":"操作成功","data":{"plotId":"1234567890123456789","position":"BOUNDARY","inBounds":true}}
```

`UNAVAILABLE` 时 `inBounds` 为 null，调用方必须看 `position`，不能把未知当成界外或界内。经纬度格式错误则返回业务错误。

## 2. 轨迹线段裁剪

```text
POST /landPlot/boundary/clip
Content-Type: application/json
```

以下为示意请求，`plotId` 必须替换为本人有权访问的实际地块ID；雪花ID使用字符串提交：

```json
{
  "plotId":"1234567890123456789",
  "points":[
    {"longitude":113.9995,"latitude":38.0005,"time":"2026-11-24T08:00:00"},
    {"longitude":114.0015,"latitude":38.0005,"time":"2026-11-24T08:02:00"}
  ]
}
```

若地块是之前导入的示例矩形（114～114.001、38～38.001），这两个端点都在田外，中间穿过田块。返回的可计中心线应从114开始，到114.001结束，源线段比例约为0.25～0.75，插值时间约08:00:30～08:01:30。

响应 `data` 字段：

| 字段 | 含义 |
| --- | --- |
| `coordinateSystem` | WGS84，保持原始经纬度，不写回高德坐标 |
| `lengthUnit` | metre |
| `inputPointCount` | 输入点数 |
| `pointPositions` | 每个输入点的状态，与输入顺序一一对应 |
| `fragments` | 留在地块内且扣除排除区后的线段片段 |
| `totalLength` | 原始中心线累计长度，米 |
| `insideLength` | 可作业中心线累计长度，米 |
| `outsideLength` | 不在原生地块多边形内的长度，包含原生空洞内部 |
| `excludedLength` | 原本在地块内、被额外排除区扣除的长度 |

片段包含 `sourceSegmentIndex`（从0开始的原始线段序号）、`startFraction`、`endFraction`（沿原始行驶方向的0～1比例）和起止点 `start/end`。时间若提供则按源线段比例插值，统一毫秒精度以消除浮点交点导致的纳秒尾数，输出ISO时间带`+08:00`。

长度使用局部球面投影，显示保留三位小数，分项独立舍入可能有末位误差。此处是累计中心线长度，同一路径往返会重复累计；B-10 的幅宽覆盖去重面积仍由既有 `calculateClippedArea` 计算，不能把本接口长度直接乘幅宽当最终结算面积。

## 裁剪处理

逐段计算轨迹与地块的交集，再减去插花地有效排除区的并集。不是只筛选“在地块内的采样点”：即使两个端点都在外面，穿过田块的中间部分也能保留。只有接触一个顶点、没有可计长度的片段不输出。沿边界行驶的中心线保留；面积核算仍只统计地块内的实际幅宽覆盖部分。

空洞、凹多边形和多个相交排除区均可处理；排除区重叠部分只扣一次。每条源线段的片段按行驶方向排列，不把不同片段直接连起来。前端对每个片段单独画线，显示高德地图时再转换坐标。

单次最多10000点。空列表、单点和重复位置可返回零长度，但仍验证地块几何。时间可以全部省略；提供时必须全部提供、升序、总时段不超过24小时。接口不擅自按时间重新排序，也不推断缺失时间。长时间漏采、转场等异常判定属于 B-11，本接口按提交的源线段裁剪。

边界与排除区必须是有效多边形，SRID为4326；兼容既有未标SRID的内存Polygon并按WGS84解释，不会执行坐标系转换。不支持跨日期变更线或超出局部投影范围的几何，无法可靠计算时返回错误。

## 权限与副作用

两接口均要求登录。管理员可检查有效地块，普通用户只能检查自己创建的地块，或自己创建／绑定终端的未删除作业单关联地块。身份从登录信息获取，请求不能指定其他用户。

接口只读，不改变地块边界、已有轨迹、作业单状态或面积；本次未运行云端数据修复或建表SQL。A-12 调用保持其原有业务权限入口，本次接入空间规则，没有扩大其业务写入范围。

## 验收操作

1. 构建并重启后端，在 Swagger“04-地块管理”找到这两个接口并登录授权。
2. 通过地块列表接口查询本人导入的“示例农田”，复制实际ID。
3. 检查其内部点（114.0005,38.0005）、边界顶点（114,38）、外部点（113.9995,38.0005），应分别得到INSIDE、BOUNDARY、OUTSIDE。
4. 用上述轨迹请求替换为该ID后提交裁剪。应有一条保留片段，两个输入点状态均为OUTSIDE，裁剪后的起止位置和插值时间符合示例。
5. 插花地、空洞和排除区用相应真实地块或隔离测试数据验证；不要通过修改共享地块边界制造测试条件。

代码测试覆盖内外边界、两端界外穿越、切点零长度、空洞、重叠排除区、反向行驶、时间插值、非法数据、权限，以及作业助手开始／结束的联调。共享库只读验证使用现有有效地块，实际核对PostGIS点状态、旧调用适配、JTS一致性与跨界裁剪；模拟作业测试没有向共享库创建作业单。实测误差校准仍属于B-17，不能由这些测试直接宣称达标。
