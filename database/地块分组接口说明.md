# B-02 行政村与片区分组

## 规则

行政村和片区是独立的两类分组，一块地可以各属于一个。使用明确编号归组，不从地址或地块名称猜测所属村。没有归属关系的地块显示为“未分组”。

- 行政村编号：由业务数据提供方提供的12位村级区划代码，名称建议填写完整行政村名称。本功能只校验格式，不声称代码已经过官方核验。
- 片区编号：业务自定义，1至64位字母、数字、下划线或短横线，首位为字母或数字，例如 `AREA-NORTH`。
- 分组字典在团队共用，同一类别同一编号只允许一个名称；重试相同编号和名称不会重复创建。
- 统计、分组筛选和归组操作都限定在当前用户创建的有效地块内。客户端不能指定另一个用户。
- 批量归组最多1000块，先锁定并校验全部地块；不存在、已删除、他人地块或写入失败均使整批失败。移出行政村不会清空片区，反之亦然。
- 分组只维护关联关系，不修改地块的边界或面积。逻辑删除后不计入统计，恢复后原归属仍保留。

## 数据库

PostgreSQL/PostGIS 中应用增量脚本 `database/land_plot_grouping_ddl.sql`。新增 `land_plot_group` 字典与 `land_plot_group_assignment` 归属表，不回填已有地块、不重建业务表。脚本可重复执行；缺表时分组查询返回 `available:false`，原有无分组条件的列表和导入继续可用。

## 接口

所有接口都要求登录。写入还要求 `field:square:update` 权限。

| 请求 | 用途 |
| --- | --- |
| `GET /landPlot/groups?type=VILLAGE` | 行政村字典与本人有效地块统计 |
| `GET /landPlot/groups?type=REGION` | 片区字典与本人有效地块统计 |
| `GET /landPlot/groups/assignments?plotIds=1,2` | 当前页地块归属，仅返回本人有效地块 |
| `POST /landPlot/groups` | 创建字典项，JSON 为 `type`、`code`、`name` |
| `PUT /landPlot/groups/assignment` | 批量归组，JSON 为 `type`、`groupCode`、`plotIds` |

ID 在 JSON 中使用字符串，避免前端丢失雪花 ID 精度。示例片区定义：

```json
{"type":"REGION","code":"AREA-NORTH","name":"北片区"}
```

归组时提交实际地块 ID 列表；传 `groupCode:null` 表示移出当前类别分组。空字符串不会被当作清空指令。

`GET /landPlot/query` 新增筛选参数：

- `groupType=REGION&groupCode=AREA-NORTH`：筛选该片区，与原有名称、地址、面积等条件取交集。
- `groupType=VILLAGE&ungrouped=true`：仅看尚未归入行政村的地块。
- 不传分组参数：保持原有查询逻辑。

分组摘要始终统计本人全部未删除地块，不随列表的名称、日期等搜索条件变化。

## 网页验证

更新代码并重启后端，在“农业作业管理 → 地块管理”查看“地块分组”面板。

1. 不做任何写入：分别切换行政村和片区，查看“未分组”的地块数与亩数，筛选后核对列表。新建表后已有地块默认都未分组。
2. 需要写入时，由用户在网页创建实际行政村或片区，勾选本人地块，点击“批量归组”。确认前检查选中数量与目标分组。
3. 再次选择该分组，核对列表、统计与每行归属。选择“移出当前类别分组”可撤销该类别的归属，不影响另一类别。

自动测试使用模拟 JDBC 和浏览器模拟响应验证写入流程，不会自动创建测试分组或修改共享地块归属。
