# 本地开发上手指南（团队共享云端数据库）

本指南面向项目组全体成员。目标：**后端在自己电脑上开发、随时改，数据库统一连云端那一套（公网直连，无需隧道），代码走 Git 协作。**

## 一、整体架构（先看懂这个）

```
你的电脑（本地开发）                         腾讯云服务器 82.156.224.217
┌──────────────────────────┐               ┌────────────────────────────┐
│ IntelliJ IDEA 跑后端      │   公网直连      │ Docker 容器（团队共享）       │
│ 浏览器跑前端 (npm run dev) │  带密码验证     │  MySQL / PostGIS / Redis / ES│
│         │                │ ────────────▶  │  另含一套完整演示环境(80端口) │
└─────────┼────────────────┘               └────────────────────────────┘
          │ 82.156.224.217:3306/5432/6379/9200
          └── 数据库端口已直接开放公网，后端填公网地址+密码即可连接
```

- **数据库/中间件**：在云端，全组共用同一份数据，公网直连、无需 SSH 隧道。
- **后端代码**：在各自电脑上跑、随时改，不用上传服务器。
- **代码协作**：走 Git 仓库，不是上传服务器。
- 云端那套完整后端保留为**演示环境**，手机/答辩随时访问，平时不用动。

## 三、三步上手

> 说明：Windows 的 `.bat` 脚本界面采用英文，是为了避开中文系统批处理编码导致的命令解析错误，照着双击即可。

### 第 1 步：拉取代码

```bash
git clone https://github.com/yeaonaiwoyehe/smart-agriculture.git
cd smart-agriculture
```

### 第 2 步：配置本地环境文件（填密码）

- 复制 `dev-local.env.example` 为 `dev-local.env`；
- 公网地址和端口已在模板里填好，只需把三处"找组长要"替换成真实密码（找组长要），保存；
- `dev-local.env` 已被 `.gitignore` 忽略，不会提交。

### 第 3 步：启动后端和前端

**后端（CMS）**：双击 `run-cms.bat`，或在 IDEA 里加载 `dev-local.env` 环境变量后启动主应用（默认端口 8088）。

**前端（CMS Web）**：双击 `run-ui.bat`，或手动：

```bash
cd AgriNav-CMS-dev-*/Agri-CMS-ui
copy .env.development.example .env.development   # Mac 用 cp，填高德 Key
npm install
npm run dev
```

启动后看终端输出的实际地址（默认 80，被占用会自动顺延，如 81），浏览器打开即可。

## 四、公网连接地址与后端环境变量

| 服务 | 公网连接地址 | 后端环境变量 |
|---|---|---|
| MySQL | `82.156.224.217:3306` | `MYSQL_HOST=82.156.224.217` `MYSQL_PORT=3306` |
| PostgreSQL/PostGIS | `82.156.224.217:5432` | `PG_HOST=82.156.224.217` `PG_PORT=5432` |
| Redis | `82.156.224.217:6379` | `REDIS_HOST=82.156.224.217` `REDIS_PORT=6379` |
| Elasticsearch | `82.156.224.217:9200` | `ES_HOST=82.156.224.217` `ES_PORT=9200` |

还需要配置对应的用户名和密码环境变量（`MYSQL_PASSWORD`、`PG_PASSWORD`、`REDIS_PASSWORD` 等）。

> **密码不在本公开文档中写明。** 请直接找组长索取后填入 `dev-local.env`；切勿把真实密码提交到仓库。

**前端高德 Key**：在 `.env.development` 中填写 `VUE_APP_AMAP_KEY` 与 `VUE_APP_AMAP_SECURITY_CODE`，或直接找组长要。

## 五、Git 协作约定

- 一人一个分支：`dev-a`/`dev-b`/`dev-c`/`dev-d`，各自在自己分支开发，最后合并到主干 `develop`。
- 详细规范见仓库根目录《Git分支策略与协作规范.md》。

## 六、共享数据库使用纪律（重要）

1. 所有人连的是**同一个库**，本地写入/修改的数据其他人立刻能看到，也会影响云端演示环境。
2. 不要手动删除他人或共享的数据；结构变更（建表、改字段）必须写成 SQL 脚本并经组长确认，不要直接在库里改结构。
3. 演示/答辩前，由组长统一重置演示数据，避免测试脏数据带到演示。

## 附：常见问题

- **后端连不上数据库**：先执行 `Test-NetConnection 82.156.224.217 -Port 5432`，确认网络通、密码正确，检查代理/安全软件。
- **报 Access denied / 密码错误**：核对 `dev-local.env` 里三处密码是否填对。
