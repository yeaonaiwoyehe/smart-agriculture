# 本地开发上手指南（团队共享云端数据库）

本指南面向项目组全体成员。目标：**后端在自己电脑上开发、随时改，数据库和中间件统一连云端那一套，代码走 Git 协作。**

## 一、整体架构（先看懂这个）

```
你的电脑（本地开发）                         腾讯云服务器 82.156.224.217
┌──────────────────────────┐               ┌────────────────────────────┐
│ IntelliJ IDEA 跑后端      │   SSH 隧道     │ Docker 容器（团队共享）       │
│ 浏览器跑前端 (npm run dev) │  加密转发      │  MySQL / PostGIS / Redis / ES│
│         │                │ ◀──────────▶  │  另含一套完整演示环境(80端口) │
└─────────┼────────────────┘               └────────────────────────────┘
          │ 127.0.0.1:13306/15432/16379/19200
          └── 隧道把云端端口映射到你电脑的本地端口，后端连 127.0.0.1 即可
```

- **数据库/中间件**：在云端，全组共用同一份数据。
- **后端代码**：在各自电脑上跑、随时改，不用上传服务器。
- **代码协作**：走 Git 仓库，不是上传服务器。
- 云端那套完整后端保留为**演示环境**，手机/答辩随时访问，平时不用动。

## 二、前置工具（首次开发前装好）

| 工具 | 版本要求 | 用途 |
|---|---|---|
| JDK | 21 | 编译运行后端 |
| Maven | 3.9+ | 后端依赖与打包 |
| Node.js | 18+（推荐 22） | 跑前端 |
| Git | 较新版本 | 代码协作 |
| IntelliJ IDEA | 社区版/旗舰版 | 后端开发 |

> Windows 10/11 与 Mac 均自带 OpenSSH（`ssh` 命令），无需额外安装。

## 三、四步上手

> 说明：Windows 的 `.bat` 脚本界面采用英文，是为了避开中文系统批处理编码导致的命令解析错误，不影响使用，照着双击即可；`.sh` 脚本保留中文注释。

### 第 1 步：拉取代码

```bash
git clone https://github.com/yeaonaiwoyehe/smart-agriculture.git
cd smart-agriculture
git checkout develop
```

### 第 2 步：配置 SSH 免密（每台电脑只做一次）

- **Windows**：双击 `setup-key.bat`
- **Mac/Linux**：终端执行 `bash setup-key.sh`

脚本会自动生成密钥，并让你输入**一次**服务器密码（输入时屏幕不显示字符，正常现象）。完成后以后连服务器不再需要密码。

### 第 3 步：开启隧道（每次开发前做，窗口保持开启）

- **Windows**：双击 `tunnel.bat`
- **Mac/Linux**：终端执行 `bash tunnel.sh`

**开发期间这个窗口/终端要一直开着，不要关；关闭即断开隧道。**

### 第 4 步：启动后端和前端

**后端（CMS）**：用 IDEA 打开 `AgriNav-CMS-dev-*` 工程，在运行配置里加入下面的环境变量，启动主应用（默认端口 8088）。

**前端（CMS Web）**：

```bash
cd AgriNav-CMS-dev-*/Agri-CMS-ui
# 复制开发环境模板，填入高德 Key（见下节）
copy .env.development.example .env.development   # Mac 用 cp
npm install
npm run dev
```

启动后看终端输出的实际地址（默认 80，被占用会自动顺延，如 81），浏览器打开即可。

## 四、端口映射与后端环境变量

隧道开启后，本地通过以下端口访问云端数据库：

| 服务 | 本地连接地址 | 后端环境变量 |
|---|---|---|
| MySQL | `127.0.0.1:13306` | `MYSQL_HOST=127.0.0.1` `MYSQL_PORT=13306` |
| PostgreSQL/PostGIS | `127.0.0.1:15432` | `PG_HOST=127.0.0.1` `PG_PORT=15432` |
| Redis | `127.0.0.1:16379` | `REDIS_HOST=127.0.0.1` `REDIS_PORT=16379` |
| Elasticsearch | `127.0.0.1:19200` | `ES_HOST=127.0.0.1` `ES_PORT=19200` |

还需要配置对应的用户名和密码环境变量（`MYSQL_PASSWORD`、`PG_PASSWORD`、`REDIS_PASSWORD` 等）。

> **密码不在本公开文档中写明。** 真实密码见组长本地的 `deploy/.env`（该文件已被 .gitignore 忽略，不会入库），请直接找组长索取后填入自己的运行配置；切勿把真实密码提交到仓库。

**前端高德 Key**：在 `.env.development` 中填写 `VUE_APP_AMAP_KEY` 与 `VUE_APP_AMAP_SECURITY_CODE`，申请地址 https://console.amap.com/dev/key/app ，或直接找组长要。

## 五、Git 协作约定

- 不要直接在 `main` 上开发，功能分支一律从 `develop` 切出，命名如 `feature/xxx`。
- 提交前先 `git pull` 同步，改完及时 push，再合并回 `develop`。
- 详细规范见仓库根目录《Git分支策略与协作规范.md》。

## 六、共享数据库使用纪律（重要）

1. 所有人连的是**同一个库**，本地写入/修改的数据其他人立刻能看到，也会影响云端演示环境。
2. 不要手动删除他人或共享的数据；结构变更（建表、改字段）必须写成 SQL 脚本并经组长确认，不要直接在库里改结构。
3. 演示/答辩前，由组长统一重置演示数据，避免测试脏数据带到演示。
4. 隧道断开时后端会报数据库连接错误，重新双击隧道脚本即可，代码不会丢。

## 附：常见问题

- **双击隧道一闪而过/报错**：检查是否已先运行 `setup-key` 完成免密；确认网络能访问公网。
- **本地 13306 等端口被占用**：本方案已避开常用的 3306/6379，若仍冲突，联系组长调整映射端口。
- **后端连不上数据库**：确认隧道窗口仍开着、未报错；用 `ssh root@82.156.224.217` 验证免密是否正常。
